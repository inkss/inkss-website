基于爱快路由的 IPV6 网络防火墙设置

枋柚梓

阅读模式

更新于：2026年6月13日

字数：1.3k 字

时长：4 分钟

本文介绍了如何在爱快路由设备上配置 IPV6 网络防火墙。

UPD：爱快更新 4.0 版本拉~

我们设置该防火墙的主要原因有以下几点：

  • 内网部分设备需要访问纯 IPv6 服务（如 IPTV），因此必须具备 IPv6 出口能力。
  • 某些内网设备缺乏自身防火墙能力，一旦直接暴露在公网 IPv6 下，将面临严重安全风险。
  • 实际上只有少量设备（如 NAS、虚拟机）需要被公网访问，其他设备不应暴露在外网。
  • 内网部署了 DDNS，将动态公网地址绑定到易记域名，这在 IPv6 场景下也会带来潜在信息外泄风险。

我们将从两个角度完成内网 IPV6 防火墙的设定：

  • 仅向指定设备分配公网 IPv6 地址；
  • 仅允许访问指定地址和端口，其余一律默认拒绝。

IPV6 地址获取

IPv6 地址的获取方式主要分为两类：路由器前缀通告（RA）+ 设备自行生成后缀；DHCPv6 主动下发一个 /128 的固定地址，也就是无状态 IPV6 和有状态 IPV6。前者实现方式是 SLAAC，后者是 DHCPv6。

由于 SLAAC 只能获取到地址，无法获取到 DNS 等信息，亦存在一种组合搭配：SLAAC + DHCPv6： DHCPv6‑Lite 或 Stateless DHCPv6，由 SLAAC 负责地址生成，DHCPv6 提供 DNS 等附加信息。

方式地址前缀网关DNSAMO
SLAAC（无状态）RARARA-100
Stateless DHCPv6（无状态 DHCPv6）RARARADHCPv6101
Stateful DHCPv6（有状态 DHCPv6）DHCPv6DHCPv6RADHCPv601~
有状态 + 无状态111

原则上，出于易于管理的角度，我们推崇使用有状态 DHCPv6。在这种方式下，所有信息由路由器统一下发管理。然而，谷歌曾明确表示，安卓设备将只支持 SLAAC 的 IPv6 地址获取方式[1]，因此，在有状态或者无状态的选取上根据个人需求而定[2]。

对于爱快系统，有状态可与 DHCPv6 黑白名单 搭配使用；而无状态则通过设置 RA 通告绑定，与 前缀静态分配 搭配使用，实现对指定设备的地址分配。

ACL 规则

一些基本知识：

  • 允许的优先级大于阻断的优先级；
  • 方向中的转发/进所描述的对象为路由器，进指内网/外网访问路由，一般只需要使用转发；
  • 连接方向匹配中原始方向为发起方发起访问的报文，可以是内网发起，也可以是外网发起，应答亦是；
  • 后缀匹配：由于前缀动态变化，而后缀固定[3]，所以匹配内网设备时使用后缀地址进行匹配；

假设运营商分配的 PD 前缀为 /60（aaaa:bbbb:cccc:ddd0::/60），即可划分 16 个 /64 子网（aaaa:bbbb:cccc:ddd0::/64 ~ aaaa:bbbb:cccc:dddf::/64），无状态下最小子网前缀要求便是 /64。

UPD：在 4.0 的版本，爱快可以基于设备 MAC 地址对无状态 IPV6 地址进行设置整理。

IPV6 禁入

全局 IPV6 禁入[4]：

协议栈协议动作方向连接方向匹配进接口出接口
IPV6任意阻断转发原始方向wanlan

效果：阻断了外网对内网的 IPV6 访问。

隐私地址禁出

协议栈协议动作方向连接方向匹配源地址进接口出接口
IPV6任意阻断转发原始方向::ff:feff:0/::ff:ff00:0lanwan

禁止通过 EUI-64 生成的无状态 IPV6 地址发起的出流量，结合上条做到该类地址完全的禁入禁出。

EUI-64 根据设备 MAC 地址生成网络后缀，故存在 MAC 地址泄露风险，算法流程如下：

  • dc:50:e6:d0:3b:d0 => dc:50:e6:d0:3b:d0
  • dc => 11011100 => 11011110 => de
  • de:50:e6:d0:3b:d0 => de:50:e6: d0:3b:d0
  • de:50:e6: d0:3b:d0 => de:50:e6:ff:fe:d0:3b:d0
  • de:50:e6:ff:fe:d0:3b:d0 => de50:e6ff:fed0:3bd0
  • de50:e6ff:fed0:3bd0 => fe80::de50:e6ff:fed0:3bd0

允许外网访问内网指定端口

协议栈协议动作方向连接方向匹配目的地址目的端口进接口出接口
IPV6tcp允许转发原始方向::abcd/::ffff8443wanlan

关于目的地址：数据包实际从 WAN 到 LAN，走向目的地址，可以根据后缀匹配填写目的地址。

假设设备 IPV6 地址为：240e:aaaa:bbbb:cccc:0000:0000:0000:0001，简写为 240e:aaaa:bbbb:cccc::1，用后缀表示该地址变 ::1/::ffff，无状态随机地址不可控。

检测

可以在 IPv6 Port Checker 处完成端口外网检测。

  1. 安卓设备在获取 IPV6 地址时必须使用无状态配置，且子网前缀要求大于等于 64。 ↩︎

  2. 由于无状态需要通过设备 MAC 地址计算得出，所以相比有状态地址，无状态地址长的多。 ↩︎

  3. 有状态地址后缀一定固定，无状态地址后缀需选用永久地址中的接口标识部分。 ↩︎

  4. TIP：未提及项保持默认值不做改动，下同。 ↩︎
