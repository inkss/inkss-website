一、饥荒联机版搭建

大致的流程是这样的：

  • 1.安装 SteamCMD
  • 2.安装饥荒服务端
  • 3.解决依赖
  • 4.上传配置文件
  • 5.定制启动脚本
  • 新建目录 steamcmd

此目录用于 steam 程序的安装目录。

  • 下载 SteamCMD 安装文件
  • 解压压缩包
  • 启动 steamcmd
  • 使用公共账户登录 Steam
  • 指定游戏文件的安装目录
  • 安装饥荒服务端
  • 退出 Steam 客户端
  • CentoS 依赖安装
  • 跳转到 DST /bin 目录
  • 链接组件
  • 上传 MOD 订阅文件
  • 上传存档配置文件
  • 上传存档文件至本目录，从本地饥荒客户端拿出的文件其实还是需要配置补充一番的。
  • 配置补全环境可参考: Linux 环境搭建饥荒服务器教程-配置饥荒服务端
  • 实际操作体验可参考: Ubuntu Server 搭建饥荒联机版服务端
