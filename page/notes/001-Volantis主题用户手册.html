一、Front-matter

front-matter
字段含义值类型值备注
layout页面布局模版Stringpost / page / docs / friends页面布局类型
title页面标题String-
date创建时间Date文件创建时间
updated更新日期Date文件修改时间
author作者IDString-对应 _data/author.yaml 中的作者
categories分类String/Array-
tags标签Array-
description文章摘要String-用于 SEO
keywords文章关键词String-用于 SEO
excerpt摘要String-手动指定摘要
link外部文章网址String-设置后页面自动跳转
headimg文章头图url-详情页显示头图，列表页显示头图
headimg_overlay列表页头图叠加层Boolfalse需 headimg 存在，标题浮在头图上
headimg_display详情页头图显示Bool-true 强制显示 / false 强制隐藏 / 未设置 默认逻辑
title_display详情页标题显示Bool-true 强制显示 / false 强制隐藏 / 未设置 默认逻辑
background背景图String-文章页背景图
top_meta顶部元信息Array/Booltrue / false / []false 隐藏 / true 默认 / [items] 自定义
bottom_meta底部元信息Array/Booltrue / false / []false 隐藏 / true 默认 / [items] 自定义
comments是否显示评论Booltrue
archive是否归档Booltrue是否出现在归档页，Post 类型
sidebar页面侧边栏Bool/Arraysidebar.for_page/for_post手动指定侧边栏
toc是否显示目录Booltrue
mathjax是否渲染公式Boolfalse
pin是否置顶Boolfalse
indent是否首行缩进Boolfalse自定义修改：缩进 2 字符
icons图标Array[]显示在归档页
references参考资料Array-{title: xxx, url: xxx}
copyright文章版权Object/Bool-type/author/ref
hidden是否隐藏文章Boolfalse基于插件支持
http451区域化规则Boolfalse不适宜在境内开放的文章
robotsRobots 标签String-页面级 robots meta 标签
encrypt文章加密Boolfalse需要配合 password 使用
password加密密码String-文章加密密码
group文档分组String-docs 布局的前后导航分组
order文档排序Number-docs 布局的排序序号
